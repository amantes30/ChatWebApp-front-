# Chat Web App

A simple real-time chat application frontend built with **React**.

This repository contains the frontend for a chat application that connects to a separate Node.js backend for user authentication and messaging. It uses **Socket.IO** for real-time communication and **Axios** for API requests.

## ✨ Features

* 🔐 User authentication
* 💬 Real-time messaging
* 👥 User-to-user conversations
* 🔄 Real-time communication with Socket.IO
* 🧭 Client-side routing
* 📱 Responsive chat interface

## 🛠️ Built With

* **React**
* **React Router**
* **Socket.IO Client**
* **Axios**
* **CSS**

## 🔗 Backend

This frontend requires the corresponding Node.js backend to be running for authentication and messaging functionality.

**Backend repository:**
https://github.com/amantes30/ChatWebApp-back

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/amantes30/ChatWebApp-front-.git
cd ChatWebApp-front-
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

Make sure the backend server is running before using the authentication and messaging features.
